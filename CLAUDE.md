# Rules for this repository (public)

- Public repo: never commit personal data, real figures, account numbers, names, tokens or setup codes.
  `demo-data.json` must stay fictional (generated by `pfm-data/tools/make_demo.py`).
- No external scripts, fonts or analytics; keep the CSP in `index.html` as strict as it is.
- Render data with `textContent` only (no `innerHTML`). Bump `CACHE` in `sw.js` when shipping changes.
